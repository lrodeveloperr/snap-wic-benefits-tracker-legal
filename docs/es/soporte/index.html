Mover el Historial a otro dispositivo

Usa la opción de exportar en la pantalla Historial para crear un respaldo y luego usa Importar Historial en el dispositivo receptor. Los registros compatibles se añaden al Historial y se omiten duplicados. El Historial importado es de solo lectura y no está diseñado para cambiar los saldos actuales de SNAP, WIC ni del presupuesto del dispositivo receptor. Protege los archivos exportados porque pueden contener tiendas, artículos, precios y transacciones.

Eliminar datos locales del rastreador

La aplicación no requiere una cuenta. Usa Configuración → Borrar todos los datos para borrar el estado activo y volver a la configuración inicial. Si utilizaste una versión anterior, una copia local de migración puede permanecer hasta que una actualización compatible la elimine o hasta que elimines la aplicación y sus datos mediante el sistema operativo. Los archivos exportados fuera de la aplicación se almacenan por separado y debes eliminarlos desde el lugar donde los guardaste.

Opciones de privacidad publicitaria

La aplicación está configurada para solicitar anuncios limitados y no personalizados. La publicidad no personalizada aún puede implicar el procesamiento por Google de datos limitados del dispositivo, ubicación aproximada, publicidad, interacción, rendimiento y diagnóstico. Cuando estén disponibles o sean requeridas, usa Legal y soporte → Opciones de privacidad para revisar las opciones publicitarias.

Preguntas sobre programas gubernamentales

No podemos emitir decisiones oficiales sobre elegibilidad, saldos, comercios o autorización de productos. Para información oficial, usa las Fuentes gubernamentales oficiales.
