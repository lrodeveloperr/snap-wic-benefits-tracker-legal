Reportar un anuncio inapropiado

Si ves un anuncio inapropiado o no adecuado para la edad, repórtalo. Incluye una captura de pantalla si es posible, la fecha y hora aproximadas y si estabas usando iPhone/iPad o Android.

Ayuda con la compra para eliminar anuncios

Para problemas con la compra o restauración, confirma primero que estás usando la misma cuenta de Apple ID o Google Play utilizada para comprar. Si la aplicación aún no reconoce el derecho, contacta soporte e indica la plataforma y describe el problema. No envíes información de tarjetas de pago.

Mover el Historial a otro dispositivo

Usa la opción de exportar en la pantalla Historial para crear un archivo de respaldo y luego usa Importar Historial en el dispositivo receptor. Los registros compatibles se añaden al Historial y se omiten duplicados. El Historial importado es de solo lectura y está diseñado para no cambiar los saldos actuales de SNAP, WIC ni el presupuesto de compras del dispositivo receptor. Mantén privados los archivos exportados porque pueden contener comercios, artículos, precios y detalles de transacciones.

Eliminar datos locales del rastreador

Actualmente la aplicación no requiere una cuenta de usuario. Para eliminar los datos locales del rastreador, usa Configuración → Borrar todos los datos. Esto devuelve la aplicación a la configuración inicial. Los archivos que hayas exportado fuera de la aplicación se almacenan por separado y debes eliminarlos desde el lugar donde los guardaste si ya no los deseas.

Opciones de privacidad publicitaria

La aplicación está configurada para solicitar anuncios no personalizados. Cuando estén disponibles o sean requeridas, usa Legal y soporte → Opciones de privacidad en la aplicación para revisar las opciones de privacidad publicitaria. Google o el sistema operativo también pueden ofrecer controles de privacidad según el dispositivo y la jurisdicción.

Preguntas sobre programas gubernamentales

No podemos emitir decisiones oficiales de elegibilidad, saldo, comercio o autorización de productos. Para información autorizada, usa las Fuentes gubernamentales oficiales.
